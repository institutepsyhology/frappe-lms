# Персональный доступ к урокам — рабочий прототип

Статус: **эксперимент; не подключён к Frappe и не защищает уроки**. Он принимает уже установленные факты и рассчитывает доступ для конкретного ученика, курса и урока. В этом прототипе предусмотрены несколько независимых оснований, личные и общие сроки, наследование или переопределение срока ученика, отдельные флаги урока, заморозка и предварительное отображение возможного сброса прогресса/удаления домашней работы. Никакие записи или домашние задания эта программа не меняет.

Смысл флагов АВО, точка отсчёта, границы дат и конкретные правила заморозки должны быть подтверждены для соответствующего курса. В прототипе граница окончания исключительная; `hidden=True` отказывает в доступе; несколько оснований объединяются по принципу «любого достаточно». Это предварительные решения для проверки, не доказанное точное воспроизведение АВО. `prerequisite_met` здесь является готовым входным фактом: определение состояния стоп-уроков ещё не реализовано. Вычисление даты по длительности не выбирает точку отсчёта автоматически.

До применения в LMS необходимы хранилище прав, настройка курсов и персональных исключений, безопасные операции и отображение ученику, подключение всех маршрутов проверки, миграция с АВО и испытания на изолированном Frappe-стенде. Серверный адаптер обязан сам проверить пользователя и принадлежность урока курсу; клиентские поля не являются доверенными фактами.

Проверка прототипа в Windows:

```powershell
$env:PYTHONPATH='src'
py -3.12 -m unittest discover -s tests -v
```
