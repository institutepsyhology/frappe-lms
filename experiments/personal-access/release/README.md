# Установка подготовленной версии

Образ собирается без сети поверх установленного образа индивидуального доступа с выключенной политикой, который сохраняет выбор YouTube/Rutube. В образ помещаются только перечисленные изменения LMS из конкретного опубликованного коммита; видео и фронтенд не пересобираются. Политика индивидуального доступа по умолчанию выключена: её включение для отдельных курсов остаётся отдельным шагом после проверки полного набора маршрутов и настроек.

До переключения всех трёх сайтов нужна резервная копия их баз и конфигурации, проверка образа и свободных ресурсов, миграция схемы, проверка сайта и откат исполняемого образа при ошибке. Резервные копии и конфигурация содержат секреты и персональные данные и остаются на сервере. Сама установка отключённой политики не означает готовности всех возможностей АВО.

`deploy_inactive.py` проверяет старый образ и выключенный переключатель, создаёт отдельную резервную копию каждой базы в новом каталоге и полностью прочитывает gzip, запускает миграцию по сайтам, переключает образ и проверяет работу сервисов и наличие новых документов. Для копирования используется `BackupGenerator` без автоматической очистки: стандартный `bench backup` падает при наличии старого каталога в папке копий и может удалять старые файлы. Для миграции задаётся `--entrypoint bench`: стандартный entrypoint образа меняет каталог assets, и его нельзя вызывать внутри временного миграционного контейнера. При ошибке после переключения сценарий возвращает предыдущий образ; миграция базы при этом автоматически не отменяется. Проверки целостности архива не равнозначны проверенному восстановлению.
