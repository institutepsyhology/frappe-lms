# Отдельный тестовый стенд

`create_stage.py` создаёт отдельные контейнеры Frappe, MariaDB и Redis в закрытой Docker-сети без опубликованных портов. Он не использует тома, базы или ключи рабочих сайтов; наличие пересечений томов проверяется перед созданием сайта. Временные пароли генерируются на сервере и сохраняются только в закрытом каталоге стенда. Существующие файлы, контейнеры и сети не перезаписываются и не удаляются. При ошибке лог остаётся в закрытом каталоге и может содержать технические данные: не публиковать его без проверки.

Перед запуском в архив помещают только отслеживаемые файлы `lms/` нужного коммита поверх точно указанного образа текущего выпуска. Факт создания сайта не подтверждает защиту уроков или совместимость с АВО: для этого нужны отдельные тесты под обычными учениками и проверка прямых маршрутов. Сценарий не разворачивает изменение на рабочих сайтах.
