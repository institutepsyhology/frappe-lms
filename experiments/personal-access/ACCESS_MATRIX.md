## Маршруты LMS, которые обязательно охватить

Исходники `44ccd5adf8e0b2823ae2406fd4d140bbf9485711` сверены с работающим сервером по SHA-256 для четырёх основных файлов. Перечень ниже — карта для проверки, не результат теста у ученика:

| Путь | Текущая точка и требуемая проверка |
|---|---|
| Содержимое урока по URL / методу | `lms/lms/utils.py:get_lesson` и `lms/lms/permissions.py:resolve_lesson_access`: учесть все персональные правила до выдачи содержимого и ссылок |
| Документ и список уроков | `lms/lms/doctype/course_lesson/course_lesson.py:has_permission` и `get_permission_query_conditions`: согласовать одиночное чтение и списки |
| Оглавление | `lms/lms/utils.py:get_course_outline`: обновить доступность и видимость для ученика; не полагаться только на UI |
| Файлы | `course_lesson.py:serve_resource`, `lms/lms/permissions.py:file_has_permission` и файловые маршруты Frappe: защищать прямые запросы и общие файлы |
| Тесты и вопросы | `permissions.py:can_access_quiz`, `utils.py` и `lms_quiz.py:submit_quiz`: учитываются все места использования теста, включая группы |
| Домашние задания | `lms_assignment_submission.py`: проверить создание, изменение, статус проверки, сроки и повторную отправку, включая прямой REST |
| Завершение и прогресс | `course_lesson.py:save_progress`, `lms_quiz.py:save_progress_after_quiz` и другие пути изменения: нельзя завершить закрытый урок или сбросить чужие данные |
| SCORM | `course_chapter.py:resolve_scorm_access`, `get_scorm_playback` и отдача пакета: проверить файл, manifest и вложенные ресурсы |
| Обсуждения и прочие производные данные | `utils.py` discussion handlers и другие способы чтения: полный аудит перед включением |

В Frappe список через `get_list` и прямой `get_all` отличаются по проверке условий, а разрешения на документы и перехват методов — отдельные механизмы. См. [официальное описание hooks](https://docs.frappe.io/framework/user/en/python-api/hooks). Одна настройка хука не доказывает, что все перечисленные пути закрыты.
