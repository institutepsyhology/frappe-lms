не используются. Изменений серверного приложения и пересборки образа нет.

## Подтверждённая запись через MCP

Независимые запросы MCP подтвердили 8 курсов и 130 уроков с аккаунтом
`mastervision`. Все 8 курсов неопубликованы, имеют оригинальную обложку,

Статические таблицы проходят проверку сохранности текста, ссылок, порядка

Курс 4 подтверждён в источнике как пустой и создан без выдуманного урока.

## Повторное чтение источника

В трёх парах снимков уроков 3/3, 1/1 и 1/4 отличаются только два UUID
узлов APE: `ape.id` и `ape.children[0].id`. Остальные значения, типы,
текст, ссылки, настройки и порядок совпадают. На изменённые UUID нет
ссылок в других полях. Причина смены UUID не установлена.

Новая проверка сохраняет свежий оригинал и использует прежний эквивалентный
снимок только для таких доказанных случаев. Реальные изменения содержания
остаются изменениями и требуют разбора. Свежий проход курса 3 завершился
`already_present` без перезаписи ранее созданного урока.

## Автономный запуск и остановки

Отдельный процесс использует проверенную копию опубликованного коммита,
журналирует начало записи урока и подтверждённый результат. Изменения
рабочей копии не подменяют код работающего задания. Профиль входа и архив
отдельны от МВЦ. Неопределённый результат записи, неверный аккаунт или
ошибка авторизации останавливают процесс сразу; десять последовательных
предсказуемых проблем одного этапа также останавливают его.

Исправлен сброс счётчиков при явном возобновлении: учитываются и обложки.
Журналы, исходные снимки, авторизация, изображения и содержимое уроков
в GitHub не включены.

видео в браузере. Нераспознанные материалы остаются в отдельном закрытом
отчёте; они не удаляются и не заменяются придуманным содержимым.

## Продолжение: HTML-картинки, base64 и временные сетевые сбои

Исходный запуск `4807c561` остановился при проверке курса 11 с
`mcp_connection_failed`, до начала записи его уроков. Независимые запросы
MCP подтвердили прежние 8 курсов и 130 уроков. Счётчик последовательных
проблем не сбрасывался без разбора причины.

В версии `57e73c02` добавлены:

- Разделение статического HTML на текст, изображения и текст в исходном
  порядке. Проверяются сохранность текста, ссылок, источников изображений и
  весь HTML, включая пустые обёртки. Неизвестные атрибуты требуют разбора.
- Узкое распознавание служебных атрибутов редактора GetCourse и заголовков
  с картинками. Оригинал остаётся в приватном снимке.
- Декодирование PNG/JPEG/JPG/WebP `data:image` без сетевого запроса:
  каноническая кодировка, ограничение 5 MiB, MIME, сигнатура и SHA256.
  Преобразователь принимает только подготовленный приватный файл с
  совпадающей контрольной суммой. Обычные ссылки с `data:` запрещены.
- Три попытки только для чтения при временном сетевом сбое. Создание и
  изменение данных автоматически не повторяются.
- Старые пустые атрибуты полноэкранного просмотра Rutube не мешают
  преобразованию подтверждённого отдельного плеера.

Анонимно проверены и закэшированы изображения АВО и GetCourse.
Savepice в уроке 1/6 сбрасывает соединение; успешное скачивание не заявляется.
В 255 исходных проверенных уроках base64 пока не наблюдалось; поддержка
проверяется на синтетическом настоящем PNG, без создания тестового курса.

Локально прошли 277 проверок конвейера; отдельно прошли 100 чистых
проверок серверного преобразования и HTML. В собранном серверном образе
прошли 115 проверок: inline-изображения 8, преобразование 77, HTML 15,

Пока импорт был остановлен, локальный сбор без запросов Frappe сохранил
