# Изолированный перенос Master Vision

Источник: `https://shop.mastervision.su`. Назначение: `https://my-lk.mastervision.su`.
Ключ аккаунта: `mastervision`. Другие аккаунты не принимаются.

Новый сборщик не меняет конфигурацию, профили, архивы, исключения и журналы
существующего переноса МВЦ. Исторический `mastervision.sqlite` остаётся образцом,
а рабочий архив создаётся отдельно в
`exports/lesson-content/mastervision-migration/mastervision-migration.sqlite`.
Данные и авторизация в репозиторий не входят.

## Что сохраняется

- Полный каталог с подтверждённой пагинацией, итогом и уникальными ID.
- Исходный HTML курса, дерево, названия, порядок, все значения формы и
  подтверждённое поле обложки.
- Исходный HTML каждого урока, полный APE и значения настроек формы,
  включая неизвестные поля и состояния флажков.
- Неизменяемые сжатые версии с контрольными суммами и отдельный журнал.
- Только метаданные ошибок и ссылки на проблемные уроки в читаемом отчёте.

Наличие сохранённой исходной настройки не означает, что соответствующее
расписание или форма домашней работы уже реализованы во Frappe. Первый этап
создаёт черновики, сохраняет исходные номера, содержание и приватный JSON.
Доступы учеников этим оператором не создаются и не изменяются.

## Запуск из репозитория

```powershell
node experiments/mastervision-migration/login.cjs
py -3 experiments/mastervision-migration/run.py --catalog-only
py -3 experiments/mastervision-migration/run.py --collect-only --limit 1
py -3 experiments/mastervision-migration/run.py --stored --course 1
py -3 experiments/mastervision-migration/run.py --stored --course 1 --apply
py -3 experiments/mastervision-migration/run.py --apply
```

Без `--apply` проверка не создаёт документы во Frappe. `--collect-only` только
сохраняет исходники. `--stored` использует завершённые проверенные снимки,
связанные контрольной точкой; не выдаёт случайный последний снимок за готовый.
Обычный запуск повторно читает состав курса после сбора всех уроков.

До записи проверяются все уроки курса и точное начало уже существующего
порядка. Каждая созданная запись сверяется через MCP. Изменённые существующие
уроки не перезаписываются. После ошибки с неопределённым результатом записи
весь запуск останавливается; сначала требуется сверить состояние назначения.

Предсказуемые проблемы отдельных курсов попадают в отчёт, остальные курсы
могут продолжаться. После десяти последовательных проблем одного этапа
запуск останавливается. `--resume` явно сбрасывает счётчики после разбора.
Ошибки аккаунта, авторизации, транспорта и идентичности останавливают запуск
сразу. Одновременно допустим один рабочий процесс для этого архива.

Профиль входа отдельный: `private-browser-profiles/mastervision`. Cookies
расшифровываются только локально и отправляются только на подтверждённый
HTTPS-домен источника. HTTP-транспорт поддерживает только чтение каталога,
редактора курса и редактора урока, не следует перенаправлениям.

## Проверки

```powershell
py -3 -m unittest discover -s experiments/mastervision-migration -p 'test_*.py'
node --test experiments/mastervision-migration/test_transport.cjs
```

Проверки используют синтетические данные. Реальные тексты, HTML, настройки,
изображения, cookie, пароли и загруженные исходники остаются в закрытом архиве.
