# Изолированный перенос Master Vision

Источник: `https://shop.mastervision.su`. Назначение: `https://my-lk.mastervision.su`.
Ключ аккаунта: `mastervision`. Другие аккаунты не принимаются.

Новый сборщик не меняет конфигурацию, профили, архивы, исключения и журналы
существующего переноса МВЦ. Исторический `mastervision.sqlite` остаётся образцом,
а рабочий архив создаётся отдельно в
`exports/lesson-content/mastervision-migration/mastervision-migration.sqlite`.
Данные и авторизация в репозиторий не входят.

## Что сохраняется

- Полный каталог с подтверждённой пагинацией, итогом и уникальными ID.
- Исходный HTML курса, дерево, названия, порядок, все значения формы и
  подтверждённое поле обложки.
- Исходный HTML каждого урока, полный APE и значения настроек формы,
  включая неизвестные поля и состояния флажков.
- Неизменяемые сжатые версии с контрольными суммами и отдельный журнал.
- Только метаданные ошибок и ссылки на проблемные уроки в читаемом отчёте.

Картинки из простых HTML-фрагментов выделяются в самостоятельные блоки
в исходном порядке с текстом и ссылками. Поддерживаются обычные адреса
подтверждённых CDN и встроенные `data:image` PNG, JPEG/JPG, WebP.
Base64 декодируется локально без сетевого запроса, проверяется формат,
размер и контрольная сумма; во Frappe создаётся приватный файл.
Предельный размер одной картинки — 5 MiB, не более 10 картинок на урок.
SVG, повреждённые данные, неизвестные настройки и неподтверждённые адреса
попадают в отчёт. Исходный HTML и APE сохраняются в закрытом архиве.

Наличие сохранённой исходной настройки не означает, что соответствующее
расписание или форма домашней работы уже реализованы во Frappe. Первый этап
создаёт черновики, сохраняет исходные номера, содержание и приватный JSON.
Доступы учеников этим оператором не создаются и не изменяются.
Подтверждённый пустой курс создаётся отдельным черновиком без выдуманного
урока. Если позднее в АВО добавят в него уроки, перед их импортом потребуется
создать соответствующую главу: текущий основной импортёр ожидает одну главу.

## Запуск из репозитория

```powershell
node experiments/mastervision-migration/login.cjs
py -3 experiments/mastervision-migration/run.py --catalog-only
py -3 experiments/mastervision-migration/run.py --collect-only --limit 1
py -3 experiments/mastervision-migration/run.py --stored --course 1
py -3 experiments/mastervision-migration/run.py --stored --course 1 --apply
py -3 experiments/mastervision-migration/run.py --stored --review-only --apply
py -3 experiments/mastervision-migration/run.py --stored --review-only --course 69 --course 135 --apply
py -3 experiments/mastervision-migration/run.py --apply
py -3 experiments/mastervision-migration/run.py --stored --covers-only --apply
py -3 experiments/mastervision-migration/run.py --stored --settings-only --apply
py -3 experiments/mastervision-migration/launch.py --apply
```

Для длительного автономного запуска `launch.py` берёт только сохранённый
коммит Git и проверяет контрольные суммы отдельной копии исходников.
Правки рабочей копии не меняют уже запущенный процесс. Закрытый журнал
`mastervision-migration/jobs/job-*.log` содержит номера и результаты этапов;
одноимённый JSON хранит PID, коммит, время начала, завершения и код выхода.
Состояние архива читается без блокировки командой
`py -3 experiments/mastervision-migration/status.py`.
Видимая страница состояния запускается командой
`py -3 experiments/mastervision-migration/progress_view.py`.
Она печатает локальный адрес, обновляется каждые пять секунд и отдельно
показывает настоящий статус рабочего процесса и состояние архива.
Страница читает данные без блокировки и не предоставляет команд управления.
Имена, содержимое уроков и данные авторизации на неё не выводятся.
`--port 61929` позволяет сохранить адрес страницы при её перезапуске.

Отдельный этап `launch.py --stored --audio-stage-only --apply` последовательно
копирует MP3 из проверенной описи прямо в закрытый каталог сайта МВ.
До первого запроса сверяются завершённые снимки и все ссылки описи.
Каждый файл проверяется по длине, типу, MP3-заголовку и контрольным суммам.
Повторный запуск проверяет уже сохранённые файлы, не повторяя неопределённые
запросы автоматически. Этот этап сохраняет файлы; регистрацию File и включение
ссылок в уроки нужно выполнить отдельно. На локальный диск аудиозаписи не идут.
После завершения загрузки `--stored --audio-import-only --apply --course 336`
регистрирует проверенные файлы через MCP и переносит выбранный курс.
`--course` повторяется для нескольких курсов МВ, включая другие курсы,
использующие те же проверенные MP3. Происхождение файлов по-прежнему сверяется
с исходной описью; новые аудиоадреса требуют отдельной подготовки.
`--review-only` пропускает уже завершённые курсы.
Подтверждённые регистрации сохраняются после каждого файла, повторный запуск
сверяет их с настоящими File. Неопределённые записи не повторяются автоматически.
В этом проходе аудио представлено обычными ссылками на приватные MP3 Frappe.
Исходные настройки плеера сохраняются в оригинальном снимке; они не считаются
реализованными элементами интерфейса ссылки. Изменение общего аудиоплеера
не входит в эту клиентскую доработку и не требует пересборки образа.
`--review-only` выбирает только оставшиеся проблемные курсы, сохраняя
порядок каталога и не проверяя заново уже завершённые курсы.
Повторяемый `--course` позволяет выбрать проверенную группу курсов;
готовые курсы при сочетании с `--review-only` пропускаются.

Обложки копируются в локальные файлы Frappe, а не подключаются с АВО.
Для проверки JPEG с EXIF нужен Pillow: Frappe удаляет метаданные,
применяет ориентацию и заново сохраняет JPEG. Проверка допускает только
исходные байты либо точный результат этого известного преобразования;
произвольные изменения файла остаются ошибкой. Уже созданный подходящий
файл переиспользуется. Для запуска с Pillow можно использовать Python
из установленного комплекта Codex:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" experiments/mastervision-migration/launch.py --stored --covers-only --apply
```
Запись каждого урока отмечается перед отправкой и после подтверждения MCP.

Без `--apply` проверка не создаёт документы во Frappe. `--collect-only` только
сохраняет исходники. `--stored` использует завершённые проверенные снимки,
связанные контрольной точкой; не выдаёт случайный последний снимок за готовый.
Обычный запуск повторно читает состав курса после сбора всех уроков.
Если АВО пересоздаёт только неиспользуемые UUID блоков, свежий оригинал всё
равно сохраняется в архиве. Для повторного импорта выбирается ранний
эквивалентный снимок после проверки отсутствия ссылок на изменённые UUID;
любое изменение текста, ссылок, типов, порядка или настроек этим правилом
не скрывается. Уже перенесённые уроки не переписываются.

До записи проверяются все уроки курса и точное начало уже существующего
порядка. Каждая созданная запись сверяется через MCP. Изменённые существующие
уроки не перезаписываются. После ошибки с неопределённым результатом записи
весь запуск останавливается; сначала требуется сверить состояние назначения.

Предсказуемые проблемы отдельных курсов попадают в отчёт, остальные курсы
могут продолжаться. После десяти последовательных проблем одного этапа
запуск останавливается. `--resume` явно сбрасывает счётчики после разбора.
Сбрасываются все этапы, включая отдельный этап переноса обложек.
Ошибки аккаунта, авторизации, транспорта и идентичности останавливают запуск
сразу. Одновременно допустим один рабочий процесс для этого архива.
Для временных сетевых сбоев проверка Frappe допускает не более трёх
попыток чтения. Запросы создания и изменения автоматически не повторяются.
Полностью прочитанные ответы MCP позволяют использовать то же HTTPS-соединение.
После простоя, неполного ответа или ошибки соединение закрывается; это правило
не повторяет отправку записывающего запроса.

Профиль входа отдельный: `private-browser-profiles/mastervision`. Cookies
расшифровываются только локально и отправляются только на подтверждённый
HTTPS-домен источника. HTTP-транспорт поддерживает только чтение каталога,
редактора курса и редактора урока, не следует перенаправлениям.

## Проверки

```powershell
py -3 -m unittest discover -s experiments/mastervision-migration -p 'test_*.py'
node --test experiments/mastervision-migration/test_transport.cjs
```

Проверки используют синтетические данные. Реальные тексты, HTML, настройки,
изображения, cookie, пароли и загруженные исходники остаются в закрытом архиве.

Для курсов МВ 377 и 486 владелец отдельно разрешил перенос без двух
отсутствующих исходных JPG. Исключение требует точного номера курса и урока,
исходного пути блока и SHA256 адреса картинки. Оно не применяется к другим
изображениям, курсам или аккаунтам. Версия нормализации 8 сохраняет оригинальный
APE и запись исключения; уже перенесённые документы не переписываются.
Те же два согласованных файла также исключаются в 11 проверенных уроках курса 331.

Версия 9 распознаёт точное служебное поле картинки `html="Изображение"`.
Два проверенных рендера АВО его не показывают; сами изображения, их адреса,
номера и настройки сохраняются. Другие подписи и неизвестные поля не удаляются.

Версия 10 дополнительно обрабатывает проверенное статическое оформление HTML,
пустые служебные виджеты обсуждения и kbd. Пустые кнопки удаляются только для
точно известных подписей «Аудиозапись» и «Материалы», без действий и содержимого.
Текст, порядок ссылок и медиа сверяются; полный оригинал остаётся в архиве.
Согласованная отсутствующая картинка в 280/1802 и 286/1857 исключается только
по точному хешу и исходному пути [7]; живая проверка HEAD/GET вернула 404.

`lesson_policy.py` хранит отдельные решения владельца: устаревшие 207/1976
и 445/4089 исключены из переноса, 598/7544 временно отложен. Полная исходная
контрольная точка курса 598 содержит 127 уроков, план переноса — 126.
Состояние `partial` и отчёт сохраняют отложенный номер. При возвращении
7544 требуется восстановить исходную позицию 95, а не дописать его в конец.
Исходные данные и уже перенесённые уроки этими решениями не переписываются.

`audit.py --output` строит локальный план готовности по завершённым снимкам,
читая по одному курсу и закрывая SQLite до обработки. Он не обращается к
сети или MCP; наличие медиаданных проверяется отдельно при переносе.
