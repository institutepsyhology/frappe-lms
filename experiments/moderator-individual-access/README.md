# Индивидуальный доступ для модераторов

Модераторы и системные администраторы видят настройки курса и урока и могут
управлять доступом через проверенные методы `access_actions`. Прямое изменение
служебных DocType правами Moderator по-прежнему не разрешено; существующие
проверки принадлежности урока, расписания, состояния и включения политики
сохраняются. Очистка прогресса и домашних заданий остаётся доступна только
System Manager. Само обновление не создаёт и не включает правила курсов.

`test_stage.py` проверяет чтение, изменение настроек и персональных сроков
модератором, отказ ученику и прямому CRUD, отказ очистки и отсутствие
автовключения на изолированных тестовых данных с откатом. Контекст сборки не
содержит контактов, ключей или выгрузок; перед установкой делаются проверенные
резервные копии, предыдущий образ сохраняется для отката.

11.11.2026: тест на отдельной базе и 21 проверка интерфейса прошли; проверены
просмотр и изменение сроков модератором, запрет прямого CRUD и очистки, отказ
ученику и отсутствие автоматического включения политики.
