# Safe import of AVO links with presentation styles

The converter preserves the link destination and text, strips only its `style` attribute, and emits the existing formatting-loss warning. Other unsupported attributes, duplicate attributes and unsafe URLs remain rejected. Original snapshots remain private attachments. This change does not reconstruct the original visual style.

The guarded release checks the exact currently installed image and starts from its independently verified parent; the current image has that parent as its exact layer prefix and adds only the two importer modules. This replaces the last layer rather than exceeding the host's overlay layer limit. The release builds an overlay containing both importer modules, tests the candidate, verifies backups and service health on the three sites, and rolls back on failure. Publish the reviewed source first and run the release from that exact commit. Verify actual MCP behavior and record the image digest and result after deployment. No real source, media or authentication data belong in this repository.
