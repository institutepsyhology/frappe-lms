# Автоматический перенос mv-centr в черновики Frappe

После установки расширения названия длиннее 512 символов фиксируются
в журнале до записи и не сокращаются. Перенос останавливается
после десяти проблемных курсов подряд.

Скрипт последовательно читает подтверждённый список курсов и уроков mv-centr,
сверяет их с текущим редактором АВО и сохранёнными снимками, проверяет каждый
урок через MCP, затем создаёт курс и уроки как черновики. Доступ ученикам не
выдаётся. Данные других аккаунтов АВО не используются.
По указанию пользователя тестовый урок mv-centr № 17 исключён из импорта;
это не относится к курсу № 17 и его другим урокам.

Двойной щелчок по `Проверить.cmd` выполняет проверку без записей во Frappe;
`Перенести-черновики.cmd` выполняет перенос. Обе кнопки начинают с курса 13:
более ранние курсы перенесены ранее, а тестовый урок 17 исключён.
Нужны доступ к АВО через ранее
настроенный отдельный профиль сборщика, подключение к Frappe и установленный
Python 3.12 и Node.js. Окно показывает только номера курсов и итог; подробный
журнал находится в `exports/lesson-content/mv-centr-frappe-import.sqlite`.
Отдельный список с номерами курсов, уроков, ссылками и причинами сохраняется в
`exports/lesson-content/ПРОБЛЕМНЫЕ-УРОКИ-mv-centr.md`. Он показывает найденные
проблемы уроков по последней проверке каждого курса. Успешно обработанные
курсы из списка убираются; изменённые исходные данные требуют новой проверки.
Для чтения без специальных программ открывайте
`exports/lesson-content/ОТЧЁТ-перенос-mv-centr.md`. Журнал и отчёт не содержат
текстов уроков, ссылок, паролей или cookie.

В `support/` сохранены версии вспомогательных скриптов, использованных при
проверке: они позволяют восстановить их по соответствующим путям в рабочем
каталоге. Действующий запуск обращается к рабочим копиям в `collector/` и
`frappe-mcp/`; базы, профиль браузера и файл доступа в репозиторий не входят.

Если десять курсов подряд требуют разбора, работа приостанавливается. При ошибке
соединения во время записи скрипт останавливается сразу: результат записи
считается неизвестным, пока его не проверят. Он не перезаписывает существующий
урок; перед новым запуском после остановки нужно изучить журнал и состояние
курса. Для снятия остановки после проверки запустите из корня проекта:

```
py -3.12 frappe-mcp-avo/experiments/avo-batch-import/frappe_batch_import.py --resume
```

Эта команда снова выполняет только проверку; для переноса добавляют `--apply`.
Можно ограничить запуск флагами `--course 21`, `--from-course 21` или
`--limit 5`. Оригинальные снимки импортированных уроков сохраняются во Frappe
приватными вложениями. Перед записью проверяются все уроки курса, а уже
имеющиеся уроки должны образовывать точное начало его порядка в АВО.
Проверка порядка запрашивает уроки группами до 100, затем восстанавливает
исходный порядок и проверяет аккаунт, курс, главу и статус каждого урока.
Проверены 9 автоматических тестов и чтение 12 уроков реального курса через MCP.

Курсы, для которых сохранённого списка уроков нет или он изменился, не
импортируются автоматически: отсутствие списка фиксируется как проблема, а не
пропускается молча. Изображения пока требуют отдельной подготовки,
неподдержанные блоки и форматирование фиксируются в журнале. Существующий
целиком курс пропускается после проверки структуры и черновиков; это не
является проверкой содержимого. Успех переноса не означает, что все стили,
домашние задания, сроки открытия и воспроизведение видео уже проверены.

Типовые коды: `unsafe_or_unrecognized_html` — оформление требует проверки;
`video_url_invalid` — ссылка на видео не прошла проверку;
колонки по решению владельца размещаются последовательно в исходном порядке;
неизвестные настройки блоков, влияющие не только на оформление, по-прежнему
требуют проверки;
разделители по решению владельца игнорируются после установки обновлённого
конвертера; старые записи в отчёте сохраняются до повторной проверки курса;
`image_requires_preparation` — изображение нужно подготовить отдельно.

Проверка 05.11.2026: шесть автоматических тестов прошли; через MCP созданы и
проверены два курса с 23 уроками в статусе черновика. Затем три курса подряд
остановились на неподдержанном HTML, и журнал зафиксировал паузу. Исходное
оформление и воспроизведение требуют отдельной визуальной проверки.

Подтверждённые пользователем изменения отдельных видео в уже созданном
черновике нужно вносить после сохранения его предыдущей версии и повторно
сверять через MCP. Приватный исходный снимок остаётся историческим; после
исправления автоматическая проверка идентичности исходнику может обнаружить
конфликт и должна остановиться для разбора. Видео, находящееся на обработке у
провайдера, требует отдельной последующей проверки воспроизведения.

После подтверждения пользователя в одном существующем черновике исправлен
адрес резервного видео; предыдущая версия сохранена отдельно, обновлённый
черновик и неизменность остальных блоков подтверждены чтением через MCP.
Видео ещё обрабатывается провайдером, воспроизведение пока не подтверждено.
