# Письменные домашние задания МВ

Для 86 заданий МВ в курсах 14, 105, 353, 354, 590 и 618 установлен режим добровольной сдачи. На изолированном сайте 22 ноября 2026 года ученик через штатное сохранение прогресса завершил урок и открыл следующий без ответа. Учитывались другие обязательные задания, тесты и индивидуальные ограничения. Для заданий с прежними настройками проверены также открытие после отправки и после одобрения. При нескольких размещениях задания форма должна указать конкретный доступный урок.

Автоодобрение настраивается отдельно для каждого задания. Проверены немедленное одобрение, граница в 24 часа, ручная оценка, возврат на доработку и повторная сдача. Учитывается время отправки ответа учеником. После повторного сохранения того же текста срок сохраняется.

Для текстовых заданий с вложениями проверена отправка закрытого файла вместе с текстом. Проверяющий может скачать файл через доступ к работе. Другому ученику файл недоступен. После снятия вложения прежний доступ проверяющего к файлу прекращается.

Проверки находятся в `test_lms_access_grant.py`, `test_lms_assignment_submission.py`, `test_assignment_answer_files.py` и `test_avo_homework_approval.py`. Для работы на сайте требуются обновление схемы, регистрация задания планировщика и сборка интерфейса.
