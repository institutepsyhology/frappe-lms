# Вход администратора в настройки должностей

Меню и окно настроек доступны не только модераторам, но и System Manager и
Administrator. Оба условия используют общую проверку `canOpenSettings`.
Сборка наследует ранее проверенный образ прав по должностям; исходники,
манифест и откат фиксируются отдельно. Изолированные проверки интерфейса
включают пользователя System Manager без роли Moderator.
