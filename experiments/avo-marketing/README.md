# Отметки запрета рассылок АВО

`custom_no_marketing_email` — отдельная отметка User/Contact, не общая
отписка Frappe: последняя блокировала бы также служебную почту. Положительные
значения `not_to_write` и `spam_clicked` из снимка АВО МВЦ объединяются по ИЛИ.
Старый снимок не снимает установленный в Frappe запрет. Сайты не смешиваются.
Для одинаковых email запрет любого контакта считается запретом адреса.

Новые записи стандартных групп проходят проверку; при переносе отметок уже
существующие записи Email Group Member помечаются отписанными. Это не заменяет
проверку перед отправкой: в данном окружении Newsletter/Email Campaign не
установлены. При внедрении любой системы массовых рассылок обязательна проверка
`lms.lms.avo_marketing.is_blocked` при выборе получателей и непосредственно до
отправки, в том числе для уже поставленных в очередь писем. Служебные письма о
счетах и восстановлении пароля через этот маркетинговый фильтр не пропускаются.
Общая гарантия для внешних рассылок или обходящих DocType группу отправителей
не заявляется. Исторический снимок не является текущей синхронизацией АВО.

`backfill_marketing_optouts.py` без аргументов считает данные без изменений;
`--apply` ставит только положительные отметки партиями до 250 ID. Метод
ограничен Administrator и соответствием домена аккаунту, операции повторяемы.
Сценарий не сохраняет адреса и пароли в отчёт. Тест `test_stage.py` использует
вымышленные данные в отдельном окружении с откатом транзакции. Сборка образа
сохраняет предыдущий образ для отката; `prepare_sites.py` сначала создаёт
проверенные копии баз без удаления других резервных копий.

Проверка 11.11.2026: 18 тестов импортёров, 31 тест интерфейса, изолированный
тест карточки и групп прошли. На трёх сайтах созданы поля, сервисы и проверки
доступности работают. Снимок МВЦ: обработаны все 213874 записи, из них у 71635
был положительный источник запрета; в момент проверки отметка стояла у 17059
уже созданных пользователей МВЦ. Неперенесённые исходные контакты будут учтены
при их последующем импорте. Эти показатели не подтверждают актуальное состояние
АВО и не подтверждают защиту рассылок через сторонние инструменты.
