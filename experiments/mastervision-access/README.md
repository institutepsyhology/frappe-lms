# Перенос индивидуальных доступов Master Vision

Источник привязан к `shop.mastervision.su`, назначение — к `my-lk.mastervision.su`. Диапазон этой выгрузки заканчивается на связи 446858 включительно. Персональные записи хранятся в закрытом каталоге сайта вне репозитория.

1. Запустить `install_receiver.py`. Он устанавливает код приёмника и сверяет контрольную сумму.
2. Войти в АВО МВ в профиле сборщика, затем запустить `node capture_worker.cjs --workers 6`. Этап читает карточки АВО и сохраняет индивидуальный список уроков, даты и заморозки в серверном архиве. Повторный запуск пропускает сохранённые карточки. Завершение подтверждается только при полной проверке диапазона. Проверить состояние можно командой `python after_capture.py --status`.
3. После публикации версии выполнить `python after_capture.py --install`, затем `python after_capture.py --follow <ревизия>`. Этот процесс можно запустить, пока идёт сбор. После завершения он читает настройки курсов тем же сеансом АВО и передаёт работу серверу. Для сбора требуется включённый компьютер с этим сеансом. Серверный этап продолжает работу самостоятельно.

Для каждой пары «контакт — курс» учитывается запись с самым большим ID в заданном диапазоне. Контакт, курс и урок сверяются по исходным ID АВО. Пустой список назначений остаётся пустым. Неоднозначные сопоставления и неподтверждённые правила отмечаются отдельно.

Ход серверного переноса записывается в `apply-state.json` и `apply.jsonl` в каталоге выгрузки. Состояние `review` означает, что часть записей требует разбора. При повторном запуске сверяются уже записанные назначения.
