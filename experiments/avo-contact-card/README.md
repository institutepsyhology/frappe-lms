# Карточка контакта АВО

Карточка выводит и редактирует данные пользователя и импортированного контакта,
включая номер и аккаунт АВО, телефон, Telegram и ВКонтакте. Для пользователя
показаны фактические записи на курсы Frappe; это не подтверждение переноса всей
истории доступов АВО. Почта пользователя меняется штатным переименованием
Frappe, которое переносит связанные документы; совпадающие адреса не сливаются.

Роль `LMS Credential Manager` назначается системным администратором отдельно.
Она позволяет работать с паролями учеников; учётные записи сотрудников
защищены отдельно. Существующий хеш Frappe необратим. Исходный пароль АВО
сохраняется в зашифрованном служебном поле только после проверки по текущему
хешу. Пароль, который менялся вне карточки, больше не показывается и не
отправляется, пока сотрудник не установит новый. Показывать пароль можно только
после явного действия сотрудника, выдача и отправка журналируются без пароля.

Письмо отправляется только на адрес самой учётной записи; Frappe стирает его
содержимое из очереди после отправки. До отправки текст письма находится в
очереди Frappe, доступной системному администратору. При отключённой или
ненастроенной исходящей почте действие сообщает об ошибке и не создаёт письмо.
SMTP, история сообщений АВО и фактическая доставка на адрес проверяются отдельно.

`create_context.py` формирует минимальный Docker-контекст из перечисленных
исходников, без ключей и выгрузок. Базовый образ зафиксирован по SHA в манифесте;
перед сборкой нужно проверить соответствие локального тега. Исходные данные и
работающие фоновые переносы не входят в контекст. Новая роль и поля должны быть
созданы для каждого сайта после резервного копирования базы.
`prepare_sites.py` создаёт отдельные проверенные копии баз и конфигураций, затем
сохраняет недостающие ключи шифрования сайтов; значения ключей не выводятся.
`deploy.py` активирует готовый образ при приостановленных импортах, создаёт роль и
поля на трёх сайтах, проверяет доступность и сохраняет путь возврата к старому
образу. Ключи и добавленные совместимые поля при откате не удаляются.
