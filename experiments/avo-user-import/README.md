# Импорт пользователей МВЦ из АВО

Источник — приватная локальная выгрузка `exports/contacts-api-all-fields/contacts.sqlite`,
доступ только на чтение. Назначение — `my-lk.mv-centr.ru`; аккаунты других АВО
в этот импорт не входят. Сценарий создаёт пользователей сайта с номером контакта
АВО, исходным паролем и без приветственного письма. Доступы к курсам не выдаёт.

По умолчанию работает предварительная проверка. Запись запускается с `--apply
--limit N`. При совпадении почты проверяется идентификатор АВО; существующие
аккаунты не изменяются. Конфликты, неподходящие данные и подтверждённые записи
фиксируются только по номеру контакта в приватном JSONL-журнале в каталоге
выгрузки, без почт, телефонов, паролей и ссылок. После 10 проблем подряд пакет
останавливается; при неопределённом результате записи останавливается сразу.
Повторный запуск проверяет наличие пользователя перед записью.

Исходники `lms/lms/avo_user_import.py` и `avo_contact_fields.py` документируют
установленный на МВЦ импорт и поля связи. Пароли, ключи и экспортные данные
в репозиторий не включаются. На 09.11.2026 выполнены тесты импортёра и
небольшие проверочные партии; перенос всей базы ещё не завершён.
